# Ao redor do mundo
Site demonstrativo desenvolvido em HTML e CSS, inspirado no desenho enviado.

## Arquivos
- `index.html`: página inicial
- `detalhes.html`: detalhes de destinos
- `categorias.html`: categorias de viagem
- `cadastro.html`: formulário demonstrativo de cadastro
- `login.html`: formulário demonstrativo de login
- `autor.html`: sobre a autora
- `style.css`: estilos compartilhados e responsivos

Abra `index.html` no navegador para visualizar. As imagens são carregadas da internet. Os formulários são apenas demonstrativos, sem sistema real de cadastro/login.

## Publicar no GitHub Pages
Envie todos os arquivos para a raiz do repositório. Em Settings > Pages, escolha `Deploy from a branch`, selecione `main` e `/ (root)` e clique em Save.
